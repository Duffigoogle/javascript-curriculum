**The rest of Friday's class · individual work + pairs for review**

Today you start (and ideally finish) **Mini Project 2**. This activity keeps you on track so you don't spend 2 hours picking an API. 😅

## ⏱️ Suggested timeline
| Time | What |

## The 4 rules of building
1. **Get data on the console first.** `console.log(data)` before you write a single line of rendering.
2. **One feature at a time.** Search → render → details → states → polish. Test after each.
3. **Commit when it works.** `git commit -m "render search results"` — small commits save lives.
4. **Stuck for 15 minutes? Ask.** Bring: what you expected, what happened, and your Network tab.

## Peer review rules
- Be kind, be specific, be helpful. "The cards look great! When I search `zzz` nothing happens — maybe add a no-results message?"
- Reviewer: **test it like a user first**, then read the code.
- Write at least **2 ⭐ things that work well** and **2 🔧 things to improve**.
